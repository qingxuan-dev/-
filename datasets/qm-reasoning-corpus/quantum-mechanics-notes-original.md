# 量子力学笔记：从你的问题出发

**整理：** Claude，根据 Ruolin 2026-11-03 的提问
**用法：** 第 0 节逐条评价你的判断；第 1 到 7 节是量子力学的骨架；第 8 节是学习路线。
**可信度标签：** `已确立`（实验和理论都很牢靠）/ `前沿`（有实验或理论，但未定论）/ `推测`（目前没有可检验的证据）

## 0. 你的判断，逐条看

| 你的说法 | 判断 | 说明 |
|---|---|---|
| 反物质是另一种物质，像正负电子一样 | 对 | 每种粒子都有反粒子，质量相同、电荷等量子数相反。电子的反粒子是正电子。`已确立` |
| 湮灭是因为它和正常物质发生了反应 | 基本对 | 粒子和反粒子相遇，可以把全部质量转化为其他粒子，最常见的是光子。电子和正电子湮灭，产生两个各 511 keV 的光子。`已确立` |
| 反物质必定有质量 | 对 | 反粒子的质量和正粒子相同，而且是正的。2023 年 CERN 的 ALPHA-g 实验观测到反氢原子在重力下向下落，和普通物质一致。`已确立` |
| 反能量有质量 | 需要修正 | 物理学里没有"反能量"这个对象。反物质携带的是普通的正能量。有一个相关但不同的概念叫"负能量"，例如卡西米尔效应里局部的负能量密度，但它不是反物质的能量。 |
| 宇宙必然是不对称的，否则正反湮灭成一片能量 | 对，而且这是物理学的一个大问题 | 观测到的宇宙几乎全是物质。大爆炸理论预期正反物质等量产生，然后几乎全部湮灭。实际残留的物质大约是每十亿个光子对应几个重子。这种不对称从哪里来，至今没有完整答案。`前沿` |
| 时间是现实变化运动产生的 | 有严肃的理论在讨论 | 在量子力学里，时间是一个外部参数，不是可观测量。有几种理论认为时间可以从"变化"或"关联"中涌现出来，见第 4 节。`前沿` |
| 光是最低渲染以及宇宙极限速度 | 后半句对，前半句是比喻 | 光速 c 是一个不变的速度上限，更准确地说是因果关系传播的最大速度。"渲染"是计算机的比喻，目前没有物理理论或实验支持"宇宙在渲染"。`推测` |
| 底层的时间变化由物理现实的变化决定 | 有对应的理论 | 和关系时间、热时间假说相近，见第 4 节。`前沿` |

## 1. 量子力学最基本的几件事

### 1.1 状态：波函数

一个量子系统的状态用波函数 ψ 描述。它不是一个具体的数值，而是一组可能性的振幅。

### 1.2 叠加

如果 A 和 B 都是可能的状态，那么它们按一定权重的组合也是一个合法的状态。这就是叠加。叠加不是"我们不知道它在哪个状态"，而是一种实际的状态，会产生干涉，这是双缝实验揭示的事。

### 1.3 玻恩规则：概率从哪里来

测量时得到某个结果的概率，等于该结果对应振幅的模平方：

$$P = |\psi|^2$$

这是量子力学和经典概率论最大的不同：振幅可以相互抵消（相消干涉），概率不能。

### 1.4 可观测量就是算符

位置、动量、能量、自旋，每一个可观测量都对应一个算符（可以理解成矩阵）。测量结果只能是这个矩阵的特征值。所以**线性代数是量子力学的母语**。

### 1.5 不确定性原理

位置和动量不能同时被精确确定：

$$\Delta x \cdot \Delta p \ge \frac{\hbar}{2}$$

这不是测量仪器不够好，而是因为这两个算符不对易（先乘谁后乘谁结果不同）。

### 1.6 薛定谔方程：状态怎么随时间变化

$$i\hbar \frac{\partial \psi}{\partial t} = \hat{H}\psi$$

Ĥ 是能量算符（哈密顿量）。注意这里的 t 是外部给定的参数，量子力学本身不解释时间从哪里来，这正连接到第 4 节你的问题。

## 2. 反物质

### 2.1 怎么被发现的

- 1928 年，狄拉克把量子力学和狭义相对论结合起来，得到的方程出现了"负能量解"。他最终把它解释为一种电荷相反的新粒子。`已确立`
- 1932 年，安德森在宇宙线里发现了正电子，证实了预言。`已确立`

### 2.2 正反粒子有什么相同、什么相反

- 相同：质量、自旋、寿命。CERN 的 BASE 实验把质子和反质子的荷质比比较到极高的精度，没有发现差别。
- 相反：电荷，以及其他守恒的量子数（重子数、轻子数等）。

### 2.3 湮灭和产生

- 湮灭：粒子 + 反粒子 → 能量（光子或其他粒子），遵守 E = mc²。
- 反过来也可以：足够的能量可以产生一对粒子和反粒子。这叫对产生。

### 2.4 为什么在量子场论里反粒子是必然的

在量子场论中，粒子是场的激发。把相对论和量子力学合在一起，场的数学结构自然要求反粒子存在。所以反物质不是额外加进去的假设，而是理论自洽的结果。

## 3. 宇宙为什么是物质多于反物质

这是你"宇宙必然不对称"那个直觉对应的真实科学问题，叫**重子不对称问题**。

### 3.1 萨哈罗夫三条件（1967）

要从正反对称的初始状态里产生出净物质，必须同时满足：

1. 存在能改变重子数的过程；
2. C 对称性和 CP 对称性被破坏；
3. 宇宙在某个阶段偏离热平衡。

### 3.2 现状

- CP 破坏在 1964 年就在 K 介子衰变中观测到了。`已确立`
- 问题在于：标准模型里已知的 CP 破坏太弱，按现有理论算出来的不对称远远小于观测值。所以一定还有标准模型以外的物理在起作用。`前沿`
- 候选方向包括：中微子的 CP 破坏（轻子生成机制）、电弱相变时期的新物理等。都还没有被确认。

### 3.3 和你直觉的关系

你说"否则不太可能形成现实"，这和宇宙学家的判断一致：如果正反物质完全对称，今天的宇宙基本只剩辐射，没有星系，也没有我们。差别只在"必然"二字：物理学目前能说"事实上不对称"，但还不能解释"为什么必然如此"。

## 4. 时间：你最有意思的那个问题

### 4.1 量子力学里时间的尴尬地位

- 在普通量子力学里，时间 t 是外部参数，不是可观测量。泡利早年就论证过，很难为时间定义一个合格的算符。`已确立`
- 在量子引力的一种表述（惠勒-德威特方程）里，时间干脆从方程中消失了。这被称为"时间问题"。`前沿`

### 4.2 时间可能是涌现出来的：三个方向

1. **佩奇-伍特斯机制（1983）**：整个宇宙的总状态不随时间变化，但如果把宇宙分成"时钟"和"其余部分"，两者之间的量子纠缠会让"其余部分"看起来在随"时钟"演化。2014 年有团队用光子在实验室里演示了这个机制的一个玩具版本。`前沿`
2. **关系时间**：时间不是一个独立存在的背景，而是事物之间变化的关系。罗韦利等人主张这一观点。`前沿`
3. **热时间假说**：罗韦利和孔涅提出，时间的流向由系统的统计（热力学）状态决定。`推测`

你说"时间本身就是现实变化运动产生的"，和第 2、3 个方向非常接近。

### 4.3 时间箭头

为什么时间只往一个方向走？主流解释是热力学第二定律：熵总是增加。而熵之所以能一直增加，是因为宇宙开始于一个熵极低的状态。为什么初始熵这么低，又是一个尚未解决的问题。`前沿`

## 5. 光速

- 光速 c 在所有惯性参考系中都相同，这是狭义相对论的出发点。`已确立`
- 更准确的理解：c 是因果影响能传播的最大速度。光恰好以这个速度运动，是因为光子没有静止质量。引力波也以 c 传播，2017 年的观测证实了这一点。`已确立`
- 对于以光速运动的光子，"它自己经历的时间"这个说法在相对论里没有良好定义，常被通俗地说成"光子不经历时间"。
- "光是最低渲染"属于比喻。如果想把它变成物理命题，需要说清楚它预言了什么现有理论没预言的、可以测量的现象。做不到这一点，它就停留在哲学层面。

---

## 6. 测量问题与诠释

薛定谔方程描述的演化是连续、确定的；可是测量时我们只看到一个结果。叠加怎么变成单一结果？这就是测量问题，至今没有共识。主要诠释：

| 诠释 | 核心主张 |
|---|---|
| 哥本哈根 | 测量导致波函数坍缩，不追问坍缩的机制 |
| 多世界 | 不坍缩，每个结果都在一个分支里实现 |
| 玻姆力学 | 粒子始终有确定位置，由导引波引导 |
| 客观坍缩（如 GRW） | 坍缩是真实的物理过程，可能和引力有关 |
| QBism | 波函数代表观察者的信念，而不是外部实在 |

这些诠释在目前所有实验上的预测基本相同，所以选哪一个，现在更多是哲学取向。客观坍缩理论是例外，它预言了可以被检验的偏差，有实验在找。

## 7. 纠缠与贝尔定理

- 两个粒子纠缠以后，对其中一个的测量结果会和另一个的结果相关，无论它们相距多远。
- 贝尔（1964）证明：任何"局域的、事先确定好答案"的理论，预言的关联都有一个上限；量子力学预言会超过这个上限。
- 实验结果站在量子力学一边。2022 年的诺贝尔物理学奖颁给了阿斯佩、克劳泽和蔡林格，表彰他们的相关实验。`已确立`
- 纠缠不能用来超光速传递信息，所以和相对论不冲突。

## 8. 学习路线

### 8.1 数学前置（对应你的数学一计划）

前面我说线性代数对考拉兹不急，但**对量子力学，线性代数是最急的**，优先级要调到第一：

1. **线性代数**：向量空间、内积、矩阵、特征值和特征向量、厄米矩阵。量子态是向量，可观测量是矩阵。
2. **复数**：振幅是复数，你学过，只需要重新接上。
3. **微积分与微分方程**：薛定谔方程是偏微分方程，先学一维的情况。
4. **概率**：期望、方差，你考拉兹那一轮已经练过。
5. **傅里叶分析**：位置和动量之间的关系，本质上就是傅里叶变换。这一块和考拉兹那边陶哲轩用的工具是同一套。

### 8.2 推荐顺序

1. 先学两能级系统（自旋 1/2、量子比特）：只需要 2×2 矩阵，就能看到叠加、测量、纠缠的全部核心概念。
2. 再学一维的薛定谔方程：无限深势阱、谐振子、隧穿效应。
3. 然后是氢原子、角动量、自旋。
4. 最后再看狄拉克方程和量子场论的入门，那时第 2 节的反物质会有完整的数学基础。

### 8.3 一个检验自己的办法

用 2×2 矩阵亲手算一次：一个自旋处在"向上"和"向下"的等权叠加中，沿另一个方向测量，得到各个结果的概率是多少。能算出来，你就跨过了量子力学的门槛。
