Syracuse 映射中的开环收缩

Open-Loop Contraction in the Syracuse Map: Multiplier Statistics, an Exact Ruin Coefficient, and the Bit-Budget Gap

摘要

研究 Collatz 映射的 Syracuse（奇数区组）约化：每个奇数 $n$ 被映到 $(3n+1)/2^{v}$，其中 $v=\nu_2(3n+1)$。在这个坐标下，笔记记录了关于区组乘子 $\mu = 3\cdot 2^{-v}$ 的四个事实。

其一，$\mu$ 的算术均值恰好是 $1$，几何均值恰好是 $3/4$。过程在一阶矩上是临界的，在对数上是严格收缩的，这解释了矩方法为何失效。

其二，相应随机游走的 Lundberg 调节系数恰好是 $\theta^\ast = 1$，它是方程 $3^\theta = 2\cdot 2^\theta - 1$ 的非平凡根。在标准独立性启发下得到简洁的界 $\Pr[\max_k n_k/n_0 \ge y] \le 1/y$。

其三（经验结论），收缩由少数区组承担：$v\ge 4$ 的区组只占全部区组的 $12.54\%$，却贡献了 $60.4\%$ 的总下行漂移。

其四，也是本文的重点：系统没有负反馈。在连续 $r$ 个不收缩（$v=1$）区组之后，终止这段游程的区组的期望赋值对 $r=0,\dots,9$ 都是 $3.00$，恰好等于 $\mathbb{E}[v\mid v\ge 2]=3$，不携带额外信息。而抵消这段游程所需的赋值随 $r$ 线性增长。因此收缩是开环的：只在长期平均意义下有保证，局部从不保证。

最后把由此产生的障碍量化为比特预算：到达 $1$ 大约需要 $2.41\log_2 n$ 个区组，而 Terras 定理只为 $\log_2 n$ 个比特提供独立性保证。缺口是 $2.41$ 倍，而不是一个 $\varepsilon$。所缺的环节被表述为一个显式假设（比特强制耦合引理）。

§1设定：区组坐标

设 $n$ 为正奇数。定义 Syracuse 映射

$$T(n) = \frac{3n+1}{2^{v(n)}}, \qquad v(n) = \nu_2(3n+1) \ge 1 .$$

$T$ 把奇数映到奇数。Collatz 猜想等价于：每条 $T$-轨道都会到达 $1$。

把一次 $T$ 的作用称为一个区组（block）。区组乘子为

$$\mu(n) = \frac{T(n)}{n} \approx 3\cdot 2^{-v(n)},$$

近似误差只来自 $+1$ 的 $O(1/n)$ 贡献。在 $\log_2$ 坐标下，每个区组的增量为

$$S = \log_2 \mu = \log_2 3 - v \approx 1.5849625 - v . \tag{1.1}$$

区组坐标并不新，它是标准约化，也出现在近期的形式化工作中（见 §8）。

例：在二进制里看一个区组

n = 13 = 1101₂
3n+1 = 40 = 101000₂  → 末尾 3 个零，v = 3
T(13) = 40 / 2³ = 5   μ = 5/13 ≈ 0.385  (近似值 3·2⁻³ = 0.375)
注 1.1（$+1$ 起了什么作用）。乘以 $3$ 是 $\mathbb{Z}_2$ 中的单位，在模 $2^k$ 的奇剩余类上是双射，因此不带来任何不可逆性。区组幺半群的全部非交换性，也就是轨道里"时间之箭"的来源，都来自非齐次项 $+1$，它是向高位传播进位的唯一来源。

符号与技巧

符号$\nu_2(m)$
2-adic 赋值：$m$ 中因子 $2$ 的个数，也就是二进制末尾零的个数。例如 $\nu_2(40)=3$。
符号$T(n)$
Syracuse 映射。把 Collatz 的"乘 3 加 1，再一路除以 2"压缩成一步，从奇数直接跳到下一个奇数。
符号$\mu,\ S$
$\mu$ 是一步的放缩倍数；$S=\log_2\mu$ 是它在对数尺度上的增量。$S>0$ 表示变大，$S<0$ 表示变小。只有 $v=1$ 时 $S\approx+0.585$，其余都为负。
技巧取对数化乘为加
轨道大小是许多乘子的乘积 $n_k = n_0\prod\mu_i$。取 $\log_2$ 后变成和 $\sum S_i$，于是可以用随机游走、大数定律、破产理论这些处理"和"的工具。
符号$O(1/n)$
大 O 记号：误差项的量级不超过常数乘 $1/n$。这里 $\mu = 3\cdot2^{-v}(1+\tfrac{1}{3n})$，$n$ 大时可忽略。
符号$\mathbb{Z}_2$、单位
2-adic 整数环，可以理解为"向左无限延伸的二进制数"。单位指有乘法逆元的元素；$3$ 是奇数，所以在 $\mathbb{Z}_2$ 中可逆。
技巧模 $2^k$ 双射
因为 $3$ 可逆，乘 $3$ 只是把模 $2^k$ 的奇剩余类重新排列，不丢失信息。所以"信息丢失"只能来自 $+1$ 引起的进位。
符号幺半群、非交换
仿射映射 $x\mapsto 3x+1$ 与除以 $2^v$ 在复合下构成幺半群（有结合律、有单位元，但不一定可逆）。复合的顺序会改变结果，这就是"非交换"。

§2赋值分布（经典结果）

命题 2.1。在奇数上按自然密度计，
$$\Pr[v \ge k] = 2^{-(k-1)}, \qquad \Pr[v = k] = 2^{-k}, \qquad k \ge 1.$$

证明。$v\ge k$ 要求 $3n+1\equiv 0 \pmod{2^k}$，即 $n\equiv -3^{-1}\pmod{2^k}$。由于 $3$ 模 $2^k$ 可逆，解唯一；并且它是奇数（若 $n$ 为偶数，则 $3n+1$ 为奇数）。模 $2^k$ 的 $2^{k-1}$ 个奇剩余类中恰有一个满足条件。$\square$

$v$成立当且仅当频率乘子
1$n\equiv 3 \pmod 4$1/2×1.5（增长）
2$n\equiv 1 \pmod 8$1/4×0.75
3$n\equiv 13 \pmod{16}$1/8×0.375
4$n\equiv 5 \pmod{32}$1/16×0.1875

矩。利用 $\sum_{k\ge1}kx^k = x/(1-x)^2$ 与 $\sum_{k\ge1}k^2x^k = x(1+x)/(1-x)^3$，取 $x=1/2$：

$$\mathbb{E}[v] = 2, \qquad \mathbb{E}[v^2] = 6, \qquad \operatorname{Var}(v) = 2 . \tag{2.1}$$

因此平均每个区组恰有一次"强制"的减半和一次"额外"的减半，整条 Collatz 轨道上奇数步与偶数步之比为 $1:2$。

命题 2.1 与 (2.1) 归功于 Terras (1976) 和 Everett (1977)，这里只用来固定常数。Terras 的更强定理是：前 $k$ 个奇偶结果由 $n \bmod 2^k$ 决定，而且当 $n$ 取遍模 $2^k$ 的剩余类时，$2^k$ 种模式各恰好出现一次。§6 会用到它。

符号与技巧

符号$\Pr[\cdot]$、自然密度
这里的"概率"指自然密度：在 $1..N$ 的奇数中满足条件的比例，当 $N\to\infty$ 时的极限。整数本身不随机，"随机"是对起点的均匀抽样。
符号$a\equiv b \pmod m$
同余：$m$ 整除 $a-b$。$n \bmod 2^k$ 就是 $n$ 二进制的最低 $k$ 位。
符号$3^{-1} \pmod{2^k}$
模逆元：满足 $3x\equiv1$ 的 $x$。例如模 $16$ 时 $3^{-1}=11$，于是 $-3^{-1}\equiv 5$，恰对应 $v\ge4$ 的条件 $n\equiv 5\pmod{16}$。
技巧计数剩余类
把"概率"变成"在 $2^{k-1}$ 个奇剩余类中数有几个满足"。唯一解给出 $1/2^{k-1}$，再相减得到 $\Pr[v=k]=2^{-k}$，即几何分布。
技巧对几何级数求导
由 $\sum x^k = \frac{1}{1-x}$ 两边求导再乘 $x$，得到 $\sum kx^k$；重复一次得到 $\sum k^2x^k$。这是计算几何分布各阶矩的标准做法。
符号$\mathbb{E}$、$\operatorname{Var}$
期望与方差，$\operatorname{Var}(v)=\mathbb{E}[v^2]-(\mathbb{E}[v])^2 = 6-4 = 2$。
技巧Terras 等分布定理
前 $k$ 步的奇偶模式与 $n$ 的最低 $k$ 位一一对应。这使得"前 $k$ 步像抛 $k$ 次公平硬币"可以被严格证明，后文比特预算的论证正建立在这里。

§3算术均值恰为 1，几何均值恰为 3/4

命题 3.1。在命题 2.1 的分布下，
$$\mathbb{E}[\mu] = 3\sum_{k\ge1} 2^{-k}\cdot 2^{-k} = 3\sum_{k\ge1}4^{-k} = 3\cdot\tfrac13 = 1,$$
而
$$\exp_2\!\big(\mathbb{E}[\log_2\mu]\big) = 2^{\log_2 3 - 2} = \tfrac34 .$$

算术均值不是"约等于 1"，而就是 $1$。这就是一阶矩方法和矩母函数方法把 Syracuse 映射看作"恰好临界"的结构性原因；而轨道本身是许多次抽样的乘积，服从几何均值，因而收缩。

作者没有找到把这一点作为命题陈述的文献，尽管它是命题 2.1 的直接推论，很可能属于民间结论。待核实

每个区组的漂移为

$$\mathbb{E}[S] = \log_2 3 - 2 = -0.4150375 . \tag{3.1}$$
注 3.2（为什么是 3）。若乘子底数为 $b$ 而不是 $3$，漂移为 $\log_2 b - 2$，当且仅当 $b<4$ 时为负。奇数底中只有 $b=3$ 低于阈值；$5n+1$ 有 $\log_2 5 = 2.32 > 2$，确实存在发散轨道。Collatz 问题位于一个宽度为 $0.415$ 的缝隙里。

符号与技巧

符号$\exp_2(x)$
即 $2^x$。$\exp_2(\mathbb{E}[\log_2\mu])$ 就是 $\mu$ 的几何均值。
技巧Jensen 不等式
$\log$ 是凹函数，所以 $\mathbb{E}[\log\mu]\le\log\mathbb{E}[\mu]$，几何均值不超过算术均值。这里差距是 $3/4$ 对 $1$，而这个差距正是收缩的来源。
技巧代入几何级数
$\mathbb{E}[\mu]=\sum\Pr[v=k]\cdot 3\cdot2^{-k} = 3\sum 4^{-k}$，公比 $1/4$ 的级数和为 $1/3$。
术语漂移、临界
漂移是随机游走每步的期望增量。"一阶矩临界"指 $\mathbb{E}[n_{k+1}/n_k]=1$，期望既不增也不减，所以只看期望得不出收缩。
技巧典型行为与平均行为
乘积的期望由罕见的大值主导，典型值由对数的期望决定（大数定律作用于 $\sum S_i$）。分析乘性过程时应在对数尺度上取平均。
审读注$5n+1$ 的发散
$5n+1$ 有发散轨道目前是被普遍相信的猜想（例如从 $7$ 出发的轨道在数值上看似无界），尚无证明。正文"确实存在"建议改为"被认为存在"。另外 $b=1$ 也低于阈值，"只有 $b=3$"可限定为 $b>1$。

§4Lundberg 系数恰为 1

把 $\{S_i\}$ 建模为服从 (1.1) 分布的独立同分布序列。这是标准启发，它在何处失效正是 §6–7 的主题。

命题 4.1。游走 $\sum S_i$ 的调节（Lundberg）系数，即 $\mathbb{E}[2^{\theta S}]=1$ 的正根 $\theta^\ast$，恰好等于 $1$。

证明。$\mathbb{E}[2^{\theta S}] = 3^{\theta}\,\mathbb{E}[2^{-\theta v}]$，且

$$\mathbb{E}[2^{-\theta v}] = \sum_{k\ge1}2^{-k}2^{-\theta k} = \frac{2^{-(1+\theta)}}{1-2^{-(1+\theta)}} = \frac{1}{2^{1+\theta}-1}.$$

于是 $\mathbb{E}[2^{\theta S}]=1$ 化为

$$3^{\theta} = 2^{1+\theta} - 1 = 2\cdot 2^{\theta} - 1 . \tag{4.1}$$

$\theta=0$ 是平凡根。代入 $\theta=1$ 得 $3=4-1$。$\square$

推论 4.2（Cramér–Lundberg 界）。启发式地，
$$\Pr\Big[\max_k \frac{n_k}{n_0} \ge y\Big] \;\le\; \frac1y . \tag{4.2}$$

数值上（§5）实测概率收敛到约 $0.43/y$，与接近 $0.43$ 的 Cramér 常数一致。

$\theta^\ast=1$ 的精确性似乎是一个值得记录的小巧合；关于 Collatz 的破产论处理已有文献，这一点可能已为人知。待核实

符号与技巧

术语i.i.d.
独立同分布。这里假设相邻区组的 $v$ 互不影响且都服从几何分布。对真实整数轨道这只是启发，不是定理。
符号$\theta^\ast$
调节系数（adjustment coefficient），保险破产论中的核心常数：使 $\mathbb{E}[e^{\theta X}]=1$ 的非零根。这里把底数 $e$ 换成了 $2$。
技巧矩母函数
$\mathbb{E}[2^{\theta S}]$ 是 $S$ 的矩母函数（以 2 为底）。它是凸的，在 $0$ 处等于 $1$；漂移为负时在 $0$ 附近先降后升，必然在某个正 $\theta$ 处再次等于 $1$。
技巧与 §3 是同一件事
$\theta=1$ 时 $2^{\theta S}=2^S=\mu$，所以 $\mathbb{E}[2^{S}]=1$ 正是命题 3.1 的 $\mathbb{E}[\mu]=1$。$\theta^\ast=1$ 与"算术均值恰为 1"是同一个等式的两种读法。
技巧鞅与极大不等式
因为 $\mathbb{E}[\mu]=1$，$M_k = n_k/n_0$ 在 i.i.d. 模型下是非负鞅。Ville（或 Doob）极大不等式给出 $\Pr[\sup_k M_k\ge y]\le \mathbb{E}[M_0]/y = 1/y$，这就是 (4.2)。
术语Cramér 常数
精确渐近 $\Pr[\cdot]\sim C/y$ 中的常数 $C\le1$。上界 $1/y$ 不紧，是因为游走越过阈值时有"超调"。

§5数值测量

所有测量采用 Terras 停止约定：每条轨道只运行到它第一次低于起始值为止。这一点很关键。若把轨道一直跑到 $1$，会引入严重的汇合偏差，因为所有轨道共享末端 $5\to16\to1$。在一次 $149{,}999$ 条完整轨道的运行中，$v=4$ 的实测频率为 $0.0867$，理论值为 $0.0625$，超出量（约 $1.52\times10^5$）几乎正好等于轨道条数。

样本：所有奇数 $3\le n<400{,}001$；$200{,}000$ 条轨道，$696{,}730$ 个区组。

5.4 极端赋值

观测到的最大单次赋值是 $v=20$，出现在区组 $n=349{,}525$，此时 $3n+1 = 1{,}048{,}576 = 2^{20}$，一个区组直接降到 $1$。

命题 5.1。对偶数 $k$，满足 $\nu_2(3n+1)=k$ 的最小奇数 $n$ 是 $n=(2^k-1)/3$，商为 $1$。对奇数 $k$，最小的这样的 $n$ 的商为 $5$。

数值：$k=3:13$，$k=4:5$，$k=5:53$，$k=6:21$，$k=10:341$，$k=20:349{,}525$。两类最小见证数都满足 $n\approx2^k/3$；因此在 $[1,N]$ 中可达到的最大赋值是 $\log_2(3N)$。对 $N=3\times10^5$ 预测为 $19.8$，实测最大值为 $20$。

符号与技巧

技巧Terras 停止约定
只统计到"首次低于起点"为止（停止时间）。这样每条轨道只贡献它自己独有的那一段，避免许多轨道重复统计同一段公共尾巴。
术语汇合偏差
不同起点的轨道会合并（例如都经过 $5\to16\to1$，其中 $3\cdot5+1=16$ 是 $v=4$）。跑到 $1$ 时这段尾巴被计入每一条轨道，所以 $v=4$ 多出了约每条轨道一次。
技巧双对数坐标
幂律 $P=C/y$ 在 $\log P$ 对 $\log y$ 的图上是斜率 $-1$ 的直线，常数 $C$ 表现为上下平移。用它可以把"指数"与"常数"分开读出。
符号$D$、$S_k$
$S_k=\log_2 3-k$ 是赋值为 $k$ 的区组的对数增量；$D$ 把所有收缩区组的下降量按频率加权求和，再看各部分所占比例。
技巧重尾贡献分解
比较"事件占比"和"效果占比"。若后者远大于前者，就说明效果由稀有的大事件主导，与"大量小损耗"的图景相反。
技巧最小见证数
$k$ 为偶数时 $4^{k/2}\equiv1\pmod3$，所以 $(2^k-1)/3$ 是整数，并且 $3n+1=2^k$ 恰好。$k$ 为奇数时 $2^k-1$ 不被 3 整除，退而取 $3n+1=5\cdot2^k$，例如 $k=3$：$3\cdot13+1=40=5\cdot8$。
术语极大游程
连续出现 $v=1$ 且两端不能再延长的一段。长度服从几何分布，所以 $M$ 段游程中最长的一段约为 $\log_2 M$。

§6没有负反馈

这是本文的核心测量。

如果大的赋值倾向于在增长之后出现，也就是说如果这台机器"知道"自己正处在高位，那么猜想就可以用 Lyapunov 论证来处理。事实并非如此。

测量 6.1（成对）。$\mathbb{E}[v_{i+1}\mid v_i=j]$，$j=1,\dots,5$：$2.0030,\ 1.9939,\ 2.0108,\ 2.0385,\ 1.9866$。平稳地停在 $2$。

测量 6.2（终止游程的赋值）。设 $r$ 为紧接在某个 $v\ge2$ 区组之前、由连续 $v=1$ 区组构成的极大游程的长度。

$r$样本数实测 $\mathbb{E}[v\mid r]$抵消所需赋值

终止赋值恒为 $3.00$，恰好等于 $\mathbb{E}[v\mid v\ge2] = (2-\tfrac12)/\tfrac12 = 3$。这纯粹是条件化的产物，不含任何关于 $r$ 的信息。抵消要求 $k^\ast(r) = 0.585r + 1.585$ 关于 $r$ 线性，在 $r\approx2.42$ 处越过 $3.00$。

推论。长度 $\ge3$ 的游程（占全部游程的 $1/8$）平均不会被终止它的那个区组偿还。这笔债只能由之后的、无条件的事件来清偿。系统中不存在恢复力。

论断 6.3（开环收缩）。在 Syracuse 映射中，收缩在长期平均意义下有保证，但不会在局部自我修正。在区组坐标下构造局部单调 Lyapunov 泛函的任何尝试，都会被测量 6.2 阻挡。

待核实 反馈的缺失隐含在 i.i.d. 启发之中，因此可能被视为已知；作者没有找到对它的测量，也没有找到把它作为障碍明确陈述的文献。

符号与技巧

符号$\mathbb{E}[X\mid A]$
条件期望：只在事件 $A$ 发生的情形里对 $X$ 取平均。$\mathbb{E}[v_{i+1}\mid v_i=j]$ 问的是"上一步是 $j$ 时，下一步平均是多少"。
技巧几何分布的无记忆性
已知 $v\ge2$ 时，$v-1$ 与 $v$ 同分布，所以 $\mathbb{E}[v\mid v\ge2]=1+\mathbb{E}[v]=3$。也可直接算：$\mathbb{E}[v;\,v\ge2]=\mathbb{E}[v]-1\cdot\Pr[v=1]=1.5$，除以 $\Pr[v\ge2]=\tfrac12$。
符号$k^\ast(r)$
抵消阈值。$r$ 个 $v=1$ 区组共上升 $r(\log_2 3-1)\approx0.585r$，终止区组要把它和自身的 $\log_2 3$ 一起抵掉，需要 $v\ge0.585r+1.585$。
术语Lyapunov 函数
动力系统中沿轨道单调下降的量。若能找到一个，并且它只在 $1$ 处取最小值，就能证明所有轨道收敛。这里要找的是局部下降，而测量表明局部上没有纠偏机制。
术语开环 / 闭环
控制论术语。闭环系统会根据当前状态施加修正（负反馈、恢复力）；开环系统的输出不影响后续输入。这里"高位"不会让之后的赋值变大。
技巧按前置游程分层
不只看相邻两步的相关性（测量 6.1），还按"累积了多少债"分组看终止事件。即使成对相关为零，这种分层也能捕捉到更长程的依赖，这里它也确认了没有依赖。

§7比特预算

Terras 定理保证：$n$ 的轨道的前 $k$ 个奇偶结果由 $n\bmod2^k$ 决定，并在其上等分布。因此每个区组都在消耗初值的低位比特。

由 (3.1)，从 $n$ 下降到 $1$ 需要

$$k \;\approx\; \frac{\log_2 n}{0.415} \;\approx\; 2.41\,\log_2 n \tag{7.1}$$

个区组。但 $n$ 只携带 $\log_2 n$ 个比特。

观察 7.1（比特预算缺口）。把轨道跑完所需的独立比特数，超过初值所提供比特数约 $2.41$ 倍。等价地说，Terras 定理只能护送轨道从 $n$ 走到 $n^{0.585}$；之后所消耗的比特不再是新鲜的。

这个缺口并不边缘，它超过两倍。

假设 7.2（比特强制耦合引理）。存在常数 $C$，使得对每个奇数 $n$，在消耗了 $n$ 的 $k$ 个低位比特之后，轨道剩余的低位结构在接下来的 $k$ 个区组上仍以 $C$-有界差异保持等分布。

假设 7.2 正是 §5 所测量而无法证明的：在每个测试过的样本规模上，剩余比特在统计上都与新鲜比特无法区分（§5.1，精确到四位小数）。有限规模上的统计不可区分并不等于对所有 $n$ 等分布；零测集恰是反例可能藏身的地方。

注 7.3（为什么启发式不够）。把映射搬到负整数上。赋值分布、漂移 $-0.415$、$\times1.5$ 的上限和无界的下限都原样保持。然而那里存在三个非平凡循环（$-1$；$-5$；$-17$）。任何只用漂移、增长有界、收缩无界的论证，都会在 $\mathbb{Z}_{<0}$ 上证出一个假命题，因此在结构上是不完整的。缺失的输入必须能区分符号，假设 7.2 是它可能所在的位置之一。

符号与技巧

技巧比特计数论证
一个 $\log_2 n$ 位的数最多只能"编码" $\log_2 n$ 次独立的公平硬币。若一个过程需要更多次独立随机性，后面的随机性必然来自前面信息的再加工，此时独立性需要另外证明。
技巧$2.41 = 1/0.415$
需要下降 $\log_2 n$ 比特，每个区组平均下降 $0.415$ 比特，于是区组数为 $\log_2 n/0.415$。
符号$n^{0.585}$
走了 $\log_2 n$ 个区组后，高度从 $\log_2 n$ 降了 $0.415\log_2 n$，剩 $0.585\log_2 n$，对应原尺度上的 $n^{0.585}$。$0.585=\log_2 3-1$。
术语等分布、差异
等分布指各种低位模式出现的频率趋于相等；差异（discrepancy）衡量与完全均匀的偏离程度。"$C$-有界差异"要求这种偏离被一个与 $n$ 无关的常数控制。
术语零测集
密度为零的例外集合。统计实验永远看不到它们，而一个反例只需一个整数，正落在这类集合里。
技巧用反模型检验论证
若一套论证的所有前提在另一个模型（这里是负整数）中也成立，而该模型的结论是假的，那么这套论证不可能证明原命题。在负整数上，$-5\to-7\to-5$ 与 $-17\to\dots\to-17$ 是非平凡循环。
符号$\mathbb{Z}_{<0}$
负整数集合。

§8与已有工作的关系，以及如实的说明

确属经典

  • 命题 2.1 与 (2.1)：Terras (1976)、Everett (1977)。
  • 区组 / Syracuse 约化是标准的，近期已被形式化；把每段赋值游程压缩为一个区组、循环与之一一对应的约化坐标表述，见于当前的 Lean 4 形式化工作（ccchallenge.org）。
  • 密度结果：Krasikov 与 Lagarias；Tao (2019) 关于对数密度意义下"几乎所有"的结果。
  • 用对数线性型排除循环：Baker；Steiner；Simons 与 de Weger；Eliahou (1993) 给出非平凡循环长度至少 $17{,}087{,}915$；Hercher 排除了 $m\le91$ 的 $m$-循环；Barina 验证了 $n<2^{71}$。

  • 命题 4.1（$\theta^\ast=1$）。

符号与技巧

术语对数密度
按权重 $1/n$ 计数的密度，比自然密度弱一些。Tao 证明了：对任意趋于无穷的 $f$，几乎所有（对数密度意义下）轨道都会降到 $f(n)$ 以下。
技巧对数线性型（Baker 理论）
一个循环要求 $2^a\approx3^b$ 极其接近，即 $|a\log2-b\log3|$ 极小。Baker 的超越数论给出这类线性型的下界，从而排除短循环。
术语$m$-循环
在一个周期中恰有 $m$ 段"上升游程"的循环。Simons–de Weger 与 Hercher 逐步排除了小的 $m$。
术语民间结论
folklore：圈内人普遍知道、但未必在正式文献中写下的结论。

§9如何推进

近期的形式化工作把猜想拆成 H1（排除发散轨道）和 H2（排除非平凡循环），在 Lean 4 中端到端验证了一套条件理论，把剩下的输入隔离为显式假设。H2 有可用的工具，即超越数论，并且已有定量进展。H1 没有。

假设 7.2 的写法是为了能作为显式假设直接放进那个框架。因此可行的下一步不是证明猜想，而是形式化验证

$$\text{假设 7.2} \;\Longrightarrow\; \text{H1},$$

从而把障碍隔离成可机器检查的形式。

更推测性地说：§7 描述的是需要沿同一条轨道同时控制阿基米德绝对值 $|x|_\infty$ 和 2-adic 绝对值 $|x|_2$。数论对每个位分别都有工具，对代数对象则由乘积公式把它们联系起来。一条 Collatz 轨道是非交换仿射幺半群中长度不断增长的一个词，不是代数对象，乘积公式不适用。这个问题似乎需要的是一种对非代数轨道也成立的 adelic 耦合。就作者所知，这样的理论尚不存在。

符号与技巧

符号H1、H2
H1：没有趋于无穷的轨道。H2：除 $1\to1$ 外没有循环。两者合起来等价于 Collatz 猜想。
术语Lean 4
交互式定理证明器。每一步推理都由计算机检查，条件理论中未证明的部分必须写成显式假设。
符号$|x|_\infty$、$|x|_2$
$|x|_\infty$ 是通常的绝对值（数的"大小"）；$|x|_2 = 2^{-\nu_2(x)}$ 是 2-adic 绝对值（被 2 整除得越多越"小"）。轨道的增长看前者，赋值看后者。
技巧乘积公式
对非零有理数 $x$，$\prod_{p\le\infty}|x|_p = 1$：所有位上的绝对值之积恒为 1。它把不同的位捆在一起，是代数数论中联合使用各个位的基本工具。
术语adelic
阿代尔（adele）观点：把实数位和所有 $p$-adic 位放进同一个对象里同时处理。"adelic 耦合"指在同一条轨道上同时控制两个位的方法。

实验轨道实验台

输入一个正整数（偶数会先除尽因子 2），查看它的 Syracuse 轨道。柱的颜色是每个区组的赋值：琥珀色为 $v=1$（增长），蓝色为 $v\ge2$（收缩），柱高为 $v$。折线是 $\log_2 n_k$，虚线是从起点出发、斜率 $-0.415$ 的平均趋势。

附录 A复现代码

from collections import Counter, defaultdict
from math import log2

LIM = 400001                      # odd starts 3 .. LIM
pair       = defaultdict(list)    # v_i -> list of v_{i+1}
after_run  = defaultdict(list)    # preceding v=1 run length -> terminating v
work, cnt  = Counter(), Counter()

for s in range(3, LIM, 2):
    n, prev, run = s, None, 0
    while n >= s:                 # Terras stopping convention
        m = 3 * n + 1
        v = (m & -m).bit_length() - 1
        cnt[v]  += 1
        work[v] += log2(3) - v
        if prev is not None:
            pair[prev].append(v)
        if v == 1:
            run += 1
        else:
            after_run[run].append(v)
            run = 0
        prev = v
        n = m >> v

tot = sum(cnt.values())
print("blocks:", tot)
print("E[v]  =", sum(k * c for k, c in cnt.items()) / tot)
print("E[mu] =", 3 * sum(c * 2.0 ** -k for k, c in cnt.items()) / tot)
print("drift =", sum(work.values()) / tot)
for r in range(10):
    L = after_run[r]
    if len(L) > 300:
        print(f"run {r}: E[terminating v] = {sum(L)/len(L):.4f}"
              f"  needed = {0.585*r + 1.585:.2f}")

单核约 20 秒。§5 与 §6 的所有数字都由此脚本或其简单变体给出（§5.4 用跑到 1 的完整轨道，§5.2 用偏移直方图）。代码中 (m & -m).bit_length() - 1 用位运算取出最低位的 1，从而直接得到 $\nu_2(m)$。
