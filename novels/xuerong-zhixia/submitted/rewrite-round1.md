- 他发现苏棠干活的时候和说话的时候不太一样。说话的时候她是一阵风，句子一串一串往外冒，中间不带换气；干活的时候她却很安静，嘴抿着，肩膀放得很低，手上的动作轻得像在拆一个不能弄响的包装。有个小男孩伸手想去揪三花的尾巴，她没起身，也没喊，只是把手里的梳子往旁边一递，说："你帮我拿一下好不好，我手酸了。"男孩接过梳子，就忘了三花的尾巴。

- 叶知行在想。 / 他想的不是要不要她，这件事他在她开口之前就已经决定了。他想的是，该给多少钱。 / 他忽然意识到自己不知道。一个十六岁的人，晚上打三个小时工，一个小时值多少钱——他对钱的感觉一直是断开的，一头是零花钱，一头是公司账户上那串他很少点开来细看的数字，中间那一段，普通人每天打交道的那一段，他从来没有真正碰过。他知道一台显卡多少钱，一缸水草的造景多少钱，却不知道一碗面在县城卖几块，一个小时的工在县城值几块。
  → 叶知行转着手里的笔。要她是肯定要的，这个用不着想。他卡在另一件事上：一个小时给多少？他知道一张显卡多少钱，一缸水草造景多少钱，可一个小时的工在县城值几块，他还真没打听过。
- 她对顾雪融没有什么很大的期望。不需要她考得多好，不需要她跟谁走得多近，也不需要她跟自己掏心窝子说什么心里话。 / 只要她每天晚上回来，吃一点饭，陪自己打一局游戏，偶尔笑一下——哪怕嘴上不承认——就够了。 / 她不知道那两只长袖底下有什么。她看见过顾雪融洗脸的时候也不撸袖子，看见过她夏天最热的那几天，宁可把衣服后背都汗湿透了，也把袖口扣着。她没问过，也不打算问。 / 她只是觉得，顾雪融像一只放在桌子边上的玻璃杯。杯子本身好好的，没缺口，没裂纹，就是放的位置不对，太靠外了，谁走过去带起一阵风，它都可能掉下去。 / 她不想当那阵风。 / 她也不知道该怎么把杯子往里推，推多了，怕它反而倒了。 / 所以她每天打两份饭，每天等，每天陪着打一局游戏。这是她能想到的、最不会碰到那个杯子的办法。
  → 有一回在水房，林小满看见顾雪融洗脸。水开得很小，她弯着腰，一捧一捧往脸上撩，袖口扣得紧紧的，水顺着下巴流进领口，袖子一滴都没沾。旁边洗衣服的女生把袖子撸到胳膊肘，问她你不热啊，顾雪融说不热。 / 林小满把自己的脸盆往旁边挪了挪，给她让出半个水龙头，什么也没问。
