# 重写第二轮：改动对照

每条是“原来 → 现在”。

## 第三至六章

- 何叔在叶家十几年了，叶知行小时候是他接送上学，再大一点是他帮着签家长通知书。名义上是管家，其实什么都管：家里的账，父亲公司的一部分杂事，叶知行闯的大部分祸。他说话永远不紧不慢，好像天塌下来，也得先等他把茶喝完。
  → 何叔在叶家十几年了。叶知行小学的家长会是他去开的，初中打架那回，检讨书上家长签字那一栏也是他签的。他说话永远不紧不慢，天塌下来，也得先等他把茶喝完。
- 叶知行想问她为什么每天五点半会路过这里——这条路不通她住的地方，也不通学校任何一个门——话到嘴边，没问出口。
  → "这儿通哪儿？" / "不通哪儿。"顾雪融眼睛盯着墙根，"别说话了，它耳朵好。"
- 何叔请了三个熟手的师傅，干活不怎么说话，一个刷墙，一个铺地，一个做木工。墙刷的是环保漆，浅米色，刷完开着窗户晾了一夜，第二天还是有一股淡淡的味道，几只猫被暂时挪去了宠物医院寄养。地面换成了耐磨的地胶，猫抓不坏，水洒了一擦就干。窗户全装了防护网，门口加了一道纱门。
  → 何叔请了三个师傅，一个刷墙，一个铺地，一个做木工，三个人一天说不了十句话。墙刷完晾了一夜还有味儿，猫先送去宠物医院寄养了。地上铺了地胶，窗户全装了防护网，门口加了道纱门。
- 这四个字他说得有点僵，说出口才发现自己从来没说过这句话。
  → 说完他自己先咳了一声。

## 第八章　值日

- 他知道这个时候再动手，他占不了便宜。一个人对五个，他打得过一个两个，打不过五个。而且这是学校旁边，他在这儿被人看见了，回头那个孙老师要是知道——
  → 他看了看陈曦，又看了看那四个，拳头攥起来，又松开。马路对面那家早点铺的老板娘又探出头来了，手里还拿着一把锅铲。

## 第九章　正常一点

- "不多。"
  → "不多。你那一拳挨得值这个价。"
- "……别这么叫。"
  → "……别这么叫。跟收保护费似的。"
- 他想说，她不会要。她会说"我会还的"，会说"不用"，会把饭放在桌洞里，跟那个过期的面包放在一起，一直放到坏掉。可是苏棠给她就不一样。苏棠是那个塞糖给她的人，是那个蹲在楼梯上用后背给她挡人的人，苏棠给她东西，她没办法用"我会还的"挡回去。 / 他没说这些。 / "……你给她，她会吃。"他说。
  → "我给，她会说'我会还的'。"他说，"然后放桌洞里，跟那个面包作伴，放到长毛。" / "你给，她没词儿。"

## 第十三章　城中村

- "你们真的觉得，"她说，"我十恶不赦吗？"
  → "我是不是，"她说，"就是，那种，挺坏的人？"
- "也许这个世界上，"顾雪融说，"本来就没有无缘无故的爱，也没有无缘无故的恨。"
  → "书上说，"顾雪融说，"世上没有无缘无故的爱，也没有无缘无故的恨。我背过。"
- "每个人做每件事，都有一个为什么。"顾雪融说，"爱有为什么，恨也有为什么。都对得上。"
  → "所以每件事都有个为什么。"顾雪融说，"跟解方程一样，代进去，左边右边都对得上。"

## 第十四章　门口

- "叶知行。" / "嗯。" / "你那边几点了？" / "跟你那边一样。三点五十。"
  → "叶知行，你那边几点了？" / "跟你那边一样，三点五十。"他说，"咱俩又不在两个时区。"
